# Feature: Transaction Ledger Dashboard

## Business Problem

Real estate agents and administrators previously lacked a centralized, real-time interface to track the signature lifecycle status of generated property contracts. Since contracts are generated automatically via DocuSign Connect pipelines, agents had to manually log in to the DocuSign console or check their emails to verify if a contract has been completed, declined, or remains pending. This creates visual blind spots and slows down deal coordination.

## Outcome

This feature implements a secure, centralized Transaction Ledger Dashboard under the storefront's protected route `/dashboard/contracts`. 

Key Outcomes:
- **Centralized Registry**: A single responsive grid/table listing all legal contracts generated by agents or system admins.
- **Role-Based Access Control (RBAC)**: Strict server-side permission checks where agents see only the contracts they initiated, and administrators see all contracts. Client roles are completely forbidden from accessing the ledger.
- **Real-Time Signature Visuals**: Color-coded badges mapping the signature lifecycle stages (`executed`, `pending_signature`, and `declined`) directly onto the UI table.
- **Decoupled API Architecture**: Powered by a stateless query service joining metadata dynamically from `legal_contracts` and `properties` tables without triggering lazy loading exceptions.
